# Countdown Event Planner

A simple, responsive event countdown app built with HTML, CSS and vanilla JavaScript.

## Features
- Add an event with a name and future date/time
- Edit and delete events
- Live countdown in days, hours, minutes and seconds
- Shows a message when an event has started or passed
- Empty-state message when there are no events
- Saves events in browser LocalStorage
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it with the VS Code Live Server extension.

No installation or build step is required.

## Files
- `index.html` - page structure
- `style.css` - page styling
- `script.js` - event handling, LocalStorage and countdown timer
